# Agricultura e Máquinas Agrícolas

## Descrição

Este projeto consiste em uma página informativa sobre agricultura e máquinas agrícolas.

O objetivo é apresentar a importância da agricultura para a sociedade e mostrar como
a mecanização e a tecnologia contribuem para aumentar a produtividade e a eficiência
das atividades realizadas no campo.

## Tema escolhido

O tema escolhido foi **Agricultura e Máquinas Agrícolas**.

A página aborda assuntos como:

- Importância da agricultura;
- Tratores;
- Colheitadeiras;
- Plantadeiras;
- Pulverizadores;
- Tecnologia no campo;
- Agricultura de precisão;
- Benefícios da mecanização agrícola;
- Segurança e manutenção de máquinas.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Estrutura

O projeto utiliza as principais estruturas semânticas do HTML5:

- `<header>`
- `<nav>`
- `<main>`
- `<article>`
- `<section>`
- `<aside>`
- `<footer>`

Também foram utilizados títulos, listas, imagens com texto alternativo
(`alt`) e citações com `<blockquote>`.

## Responsividade

O site foi desenvolvido para funcionar em computadores, tablets e celulares,
utilizando CSS3 e Media Queries.
